EasySB repository

Package sources for the EasySB panel. The sing-box core is compiled in, so a package install is the whole install.

One-click

bash <(curl -fsSL https://raw.githubusercontent.com/MinimaxFlora/EasySB/master/install.sh)

Sources

Debian/apt flat apt archive
Fedora/rpm/$basearch rpm-md repository
Arch/pacman/$arch pacman database
Binaries/bin release tarballs

Install by source

bash <(curl -fsSL https://raw.githubusercontent.com/MinimaxFlora/EasySB/master/install.sh) --method repo
